## 一、单项选择题（1–40，每题 2 分，共 80 分）

### 1. 函数调用时的栈内容
```c
int S(int n) { return (n<=0) ? 0 : S(n-1)+n; }
void main() { cout << S(1); }
```
程序运行时用栈保存调用过程信息，自栈底到栈顶依次是？

A. `main()→S(1)→S(0)`　B. `S(0)→S(1)→main()`　C. `main()→S(0)→S(1)`　D. `S(1)→S(0)→main()`

**答案**：A

**解析**：调用关系的发生顺序是 `main` 先压栈，`main` 调用 `S(1)`，`S(1)` 再调用 `S(0)`。栈是后进先出结构，**先发生的调用在栈底、后发生的在栈顶**，故自栈底向栈顶为 `main()→S(1)→S(0)`。选项 C 把调用顺序按返回值顺序写反了。

**第一性考点**
- **本质**：栈保存的是「调用链的时间顺序」，栈底 = 最早发生的调用。
- **判据**：自底向顶 = 调用发生的先后；自顶向底 = 返回的先后。两种问法互为逆序，题目问哪个就按哪个读。
- **迁移**：递归求值、表达式求值、括号匹配都靠这一条；408 里凡是「栈中内容」「栈顶元素」的题，先确定压栈顺序再读方向。

### 2. 先序序列对应的二叉树个数
先序序列为 `a,b,c,d` 的不同二叉树个数是？

A. 13　B. 14　C. 15　D. 16

**答案**：B（14）

**解析**：给定先序序列（结点按先序的排列），只确定了「谁是根」，**左右子树的划分方式**仍是自由的：根固定为 `a`，把剩下的 `b,c,d` 切成「左子树长度 $k$ + 右子树长度 $3-k$」，$k=0,1,2,3$ 共 4 种切法，每种切法内部递归计数。设 $f(n)$ 为 $n$ 个结点的形态数：
$$f(0)=1,\quad f(n)=\sum_{k=0}^{n-1} f(k)f(n-1-k)$$
即卡特兰数 $f(n)=\dfrac{1}{n+1}\dbinom{2n}{n}$：$f(1)=1,f(2)=2,f(3)=5,f(4)=14$。

**第一性考点**
- **本质**：先序/后序序列**只锁根的位置，不锁子树的划分**；中序序列才同时锁住左右边界。
- **判据**：给「先序 / 后序」求形态数 ⇒ 卡特兰数 $C_n$；给「先序 + 中序」求形态数 ⇒ 唯一确定（1 棵）。
- **迁移**：中序 + 先序可唯一还原；先序 + 后序不能唯一还原（除满二叉树），这是同一判据的两种表现。出栈序列合法数同理是 $C_n$。

### 3. 同一棵哈夫曼树上的两条路径
从根到两个叶结点的两条路径上的权值序列，能属于同一棵哈夫曼树的是？

A. 24,10,5 和 24,10,7　B. 24,10,5 和 24,12,7　C. 24,10,10 和 24,14,11　D. 24,10,5 和 24,14,6

**答案**：D

**解析**：哈夫曼树的每个内部结点，其权值**恰等于左右孩子权值之和**，且树中不存在度为 1 的结点。逐项校验「公共前缀处两结点是否为兄弟、其和是否等于父」：
- A：根的第二个孩子只有 10 一条路，而 10 的两个孩子是 5 与 7，$5+7=12\ne10$ ✗
- B：根的两个孩子是 10 与 12，$10+12=22\ne24$ ✗
- C：路径 $24\to10\to10$ 要求叶权等于父权，$10>0$ 不可能（内部结点权 = 两子之和，必大于任一子）✗
- D：$10+14=24$ ✓；$10=5+5$ ✓；$14=6+8$ ✓ —— 每层都满足「父 = 两子之和」✓

**第一性考点**
- **本质**：哈夫曼树 = **带权外部路径长度最小**的严格二叉树；决定形态的唯一硬约束是「内部结点权 = 两子权之和」。
- **判据**：给路径权值序列，判是否同一棵树 ⇒ 从根往下**逐层验兄弟和**；只要出现「叶权 = 父权」或「兄弟和不等于父权」立刻排除。
- **迁移**：构造哈夫曼树时每次合并**最小的两个**，本质就是让「和」尽可能小给浅层；判定哈夫曼编码、算 WPL 都从这条硬约束出发，不必死记树的形状。

### 4. 中序遍历为降序的平衡二叉树
一棵无重复关键字的 AVL 树，中序遍历得到降序序列。下列叙述正确的是？

A. 根结点的度一定为 2　B. 树中最小元素一定是叶结点　C. 最后插入的元素一定是叶结点　D. 树中最大元素一定是无左子树

**答案**：D

**解析**：中序降序 ⇒ 树中任意结点的**左子树关键字都比它大、右子树都比它小**（普通 BST 的镜像）。
- A 错：AVL 允许度为 1 或 0 的结点（如两结点的树）。
- B 错：最小元素是中序的最后一个，按「左大右小」它只需要**无右子树**，仍可能有左子树（左子树里的元素都比它大，不影响它最小），故不一定是叶结点。
- C 错：插入后若触发**双旋转**（如先插到某子树的「内侧」引发 LR/RL），新结点会被转到子树的根位置，从而成为**度为 2 的内部结点**，不再是被插入时那个叶子的角色。
- D 对：中序第一个元素就是最大元素；中序第一个 ⇒ 它之前没有左子树（中序先访问左子树），故最大元素**一定无左子树**。

**第一性考点**
- **本质**：中序序列的顺序就是「左 → 根 → 右」的展开；因此**序列的首尾必然对应最深层的那条链**。
- **判据**：问「最大/最小元素有无某子树」⇒ 看中序首尾位置，最大元素无左子树、最小元素无右子树（正序 BST 时反过来）。
- **迁移**：正序 BST 中最小元素无左子树、最大元素无右子树；镜像后左右对调。AVL 的旋转可以改变结点位置，所以凡涉及「插入的元素一定在什么位置」的判断，一律考虑双旋转反例。

### 5. 从 V0 出发的深度优先遍历序列个数
有向图 $G=(V,E)$，$V=\{V_0,V_1,V_2,V_3\}$，$E=\{\langle V_0,V_1\rangle,\langle V_0,V_2\rangle,\langle V_0,V_3\rangle,\langle V_1,V_3\rangle\}$。从 $V_0$ 开始 DFS，可能得到的不同遍历序列个数是？

A. 2　B. 3　C. 4　D. 5

**答案**：D（5）

**解析**：DFS 的序列差异只来自**同一顶点的多个邻接点的访问先后**（邻接表次序不同）。
$V_0$ 出发后第二个顶点可以是 $V_1$、$V_2$、$V_3$ 之一，分情况枚举：
1. 先 $V_1$：$V_1$ 有出边到 $V_3$ → 序列 $V_0,V_1,V_3,V_2$（1 个）
2. 先 $V_2$：$V_2$ 无出边，回溯到 $V_0$ 后剩 $\{V_1,V_3\}$，可先 $V_1$（$V_1\to V_3$）或先 $V_3$ → $V_0,V_2,V_1,V_3$、$V_0,V_2,V_3,V_1$（2 个）
3. 先 $V_3$：$V_3$ 无出边，回溯后剩 $\{V_1,V_2\}$ → $V_0,V_3,V_1,V_2$、$V_0,V_3,V_2,V_1$（2 个）

合计 $1+2+2=5$。

**第一性考点**
- **本质**：DFS 序列 = **「按某邻接次序走到不能走再回溯」**；序列不唯一，唯一由邻接表次序决定。
- **判据**：求序列个数 ⇒ 枚举「第二个顶点是谁」再对每个分支递归；某顶点无出边就会立刻回溯，不要再往下编。
- **迁移**：BFS 同理（序列差异来自队列中同层顶点的出队次序）；拓扑序列个数、DFS 生成树形态数都是同一「分支枚举」动作。

### 6. Kruskal 与 Prim 的第 2 条选中边（**题面含图 · 待核验**）
（底本 P1–P2 给出一张带权无向图）求最小生成树时，可能被 Kruskal 算法第 2 次选中、但不是 Prim 算法（从 $V_4$ 开始）第 2 次选中的边是？

A. $(V_1,V_3)$　B. $(V_1,V_4)$　C. $(V_2,V_3)$　D. $(V_3,V_4)$

**答案**：C

**解析**：两个算法的第 1 条边都是**全图最小权边**，所以「第 2 条边是否相同」的差别只在于：
- **Kruskal**：在全图剩余的边里继续挑权值最小的（不看连通性，只看是否成环）；
- **Prim（从 $V_4$ 出发）**：只在**当前已选顶点集 $U$ 到 $V\setminus U$ 的割边**里挑最小权边。
因此「Kruskal 选、Prim 不选」的边，其权值必然**小于或等于** Prim 在第 2 步会选的那条割边——即该边不在 $V_4$ 起步的割边集里，或它在割边集里但权值不是最小。底本答案：$(V_2,V_3)$。

> ⚠ 待核对：本题的**边权数值**在底本中是图片，本机无视觉通道，无法复算具体数值。已逐条核对官方答案页为 C；请对照底本 P1 的带权图复核第 2 步的两条边。

**第一性考点**
- **本质**：Kruskal 是**全局贪心**（按权值排序取边），Prim 是**局部贪心**（按割集取边）；两者都正确，只因为「最小生成树的边权多重集唯一」。
- **判据**：比较两算法的第 $k$ 步 ⇒ 看第 $k-1$ 步是否已经产生分歧：只要前 $k-1$ 条边相同，第 $k$ 条就只可能因「是否在同一割集内」而不同。
- **迁移**：MST 的「权值和唯一、形态可能不唯一」这一性质，是判断「某边是否一定在 MST 中」的依据；等价判据是「该边是否是该环上的唯一最大权边」。

### 7. 不可能出现的折半查找比较序列
下列选项中，不能构成折半查找中关键字比较序列的是？

A. 500,200,450,180　B. 500,450,200,180　C. 180,500,200,450　D. 180,200,500,450

**答案**：A

**解析**：折半查找每次比较都把**当前查找区间**砍半，所以序列中每后一个值都必须落在「上一个比较值确定的那半个区间」内，即区间需要**不断收缩**：
- A：500 → 目标 < 500，进左半 → 200 ✓；200 → 目标 > 200，进 $(200,500)$ → 450 ✓；450 → 目标 < 450，进 $(200,450)$ → 但下一个是 180，落在区间外 ✗
- B：500 → $(?,500)$ → 450 ✓ → $(-\infty,450)$ → 200 ✓ → $(-\infty,200)$ → 180 ✓
- C：180 → $(180,?)$ → 500 ✓ → $(180,500)$ → 200 ✓ → $(200,500)$ → 450 ✓
- D：180 → $(180,?)$ → 200 ✓ → $(200,?)$ → 500 ✓ → $(200,500)$ → 450 ✓

**第一性考点**
- **本质**：折半查找的比较序列本质是**一棵二叉判定树上的一条根到叶路径**，每次比较都必须朝「可行区间」的方向走。
- **判据**：把每个比较值当成新的区间端点，检查下一个值是否仍落在剩余区间内；出界即非法。
- **迁移**：这条判据同时解释了「折半查找的判定树是什么形状」和中序有序性；B 树的查找路径、二叉排序树的比较序列也都能用「区间必须一直收缩」来验。

### 8. KMP 失配后 i、j 的取值
$S=$`abaabaabacacaabaabcc`，$t=$`abaabc`。匹配到第一次失配（$S[i]\ne t[j]$）时 $i=j=5$，则下次开始匹配时 $i,j$ 分别是？

A. $i=1,j=0$　B. $i=5,j=0$　C. $i=5,j=2$　D. $i=6,j=2$

**答案**：C

**解析**：KMP 的核心是**主串指针 $i$ 永不回溯**，只把模式串右滑。滑动多少由 `next` 决定：$j$ 处失配时，令 $j\leftarrow \text{next}[j]$，其中 $\text{next}[j]$ = 模式串前缀 $t[0..j-1]$ 的**最长相等真前缀与真后缀**的长度。
本题 $j=5$，考察 $t[0..4]=$`abaab`：真前缀集合含 `ab`，真后缀 `ab`，最长相等长度 2 ⇒ $\text{next}[5]=2$。故 $i=5$、$j=2$。

**第一性考点**
- **本质**：KMP 加速的本质是**利用已匹配部分的自相似性，避免主串回溯**——「已匹配的前缀里，尾部有片段等于头部」才能安全右滑。
- **判据**：$j$ 处失配 ⇒ 新 $j = $ 模式串前 $j$ 个字符的最长公共前后缀长度；主串 $i$ 不动。
- **迁移**：求 `next` 数组（含 $-1$ 起始约定）、求字符串最短循环节（$n-\text{next}[n]$）、AC 自动机的 fail 指针都是这一条。

### 9. 元素移动次数与初始次序无关的排序
下列排序算法中，元素移动次数与关键字初始排列次序无关的是？

A. 直接插入排序　B. 起泡排序　C. 基数排序　D. 快速排序

**答案**：C

**解析**：前三者都靠**相邻/分治比较交换**，比较与移动次数随初始有序程度剧烈变化（插入排序在正序时移动 0 次、逆序时 $O(n^2)$；起泡排序同理；快排在正序/逆序时最差）。基数排序是**分配—收集**：每趟把 $n$ 个元素按当前位分配到 $r$ 个桶再按序收回，无论初始次序如何，每趟都恰好移动 $n$ 次，总计 $O(dn)$ 次移动。

**第一性考点**
- **本质**：移动次数是否依赖初态，取决于算法**是否用「比较结果」决定移动**。基数排序的移动量由「位数 × 元素数」决定，与关键字大小关系无关。
- **判据**：题目出现「与初始排列次序无关」⇒ 排除一切**基于比较的排序**；只剩基数排序（以及计数/桶排序这类非比较排序）。
- **迁移**：反之「比较次数与初始状态无关」的典型是**简单选择排序**（总是 $n(n-1)/2$ 次比较）与**堆排序/归并排序**（与初态无关）；把这两组区分开就不会混。

### 10. 小根堆删除堆顶后的比较次数
已知小根堆为 8,15,10,21,34,16,12，删除关键字 8 之后需重建堆，此过程中关键字之间的比较次数是？

A. 1　B. 2　C. 3　D. 4

**答案**：C（3 次）

**解析**：小根堆按层序存于一维数组（下标 1 起）：`[8,15,10,21,34,16,12]`。
1. 删除堆顶：把**最后一个元素 12** 移到堆顶，堆变为 `[12,15,10,21,34,16]`（规模 6）。
2. 从根向下「筛」：根的左右孩子是 15、10 → 先比较 $15$ 与 $10$ 取小（第 1 次比较），再拿 12 与 10 比（第 2 次比较），$12>10$ 需交换 → `[10,15,12,21,34,16]`。
3. 12 落到下标 3，其孩子只有下标 6 的 16（下标 7 已空）→ 12 与 16 比（第 3 次比较），$12<16$ 满足堆序，停止。

共 3 次比较。

**第一性考点**
- **本质**：堆删除 = 「末元素补根 + 自顶向下筛选」，筛选的代价是**每层最多 2 次比较**（孩子间 1 次 + 父与较小孩子 1 次）。
- **判据**：比较次数 = 下滑**层数 × 2 −（单孩子层少 1 次）**；题目的坑就在「下标 6 只有单孩子」时不能多算一次比较。
- **迁移**：建堆（自底向上筛选）比较次数上界 $4n$、堆排序每趟 $O(\log n)$ 的比较次数估算都用这个「每层 2 次」的模型。

### 11. 希尔排序的组内排序方法
希尔排序的组内排序采用的是？

A. 直接插入排序　B. 折半插入排序　C. 快速排序　D. 归并排序

**答案**：A

**解析**：希尔排序 = 「按增量 $d$ 分组，对每组做**直接插入排序**，再缩小 $d$ 重复」。它只改变插入排序的「步长」，组内仍是逐个取元素、在组内已排好序的序列中**从后往前找插入位置**的直接插入排序。

**第一性考点**
- **本质**：希尔排序是对直接插入排序的改造——**利用「基本有序时插入排序接近 $O(n)$」** 这一性质，先用大增量把序列变得基本有序。
- **判据**：见到「增量/步长分组 + 组内排序」⇒ 组内一定是直接插入（因为直接插入对局部有序最敏感、且是原地少量元素移动）。
- **迁移**：$d=1$ 时希尔排序退化为直接插入排序，这既是「稳定性被破坏」的原因，也是判断增量序列合法性的依据。

### 12. 计算机硬件能直接执行的程序
计算机硬件能够直接执行的是？
Ⅰ．机器语言程序　Ⅱ．汇编语言程序　Ⅲ．硬件描述语言程序

A. 仅Ⅰ　B. 仅Ⅰ、Ⅱ　C. 仅Ⅰ、Ⅲ　D. Ⅰ、Ⅱ、Ⅲ

**答案**：A

**解析**：CPU 只能识别**二进制机器指令**。汇编语言程序须经汇编程序翻译成机器语言；硬件描述语言（Verilog/VHDL）描述的是电路行为，须经综合工具变成门级网表，两者都不是 CPU 能直接执行的形态。Ⅰ 是唯一直接可执行的。

**第一性考点**
- **本质**：CPU 的执行单元只认**指令操作码 + 操作数编码**，任何高级形式都必须先「翻译成指令」。
- **判据**：问「能否直接执行」⇒ 看该形式是否已是指令的二进制编码；带助记符（汇编）、带语法结构（高级语言/HDL）都不行。
- **迁移**：翻译层次由低到高：机器码 →（汇编器）汇编 →（编译器）高级语言；解释执行（如 Python 字节码）本质仍是「先翻译成机器指令序列」。

### 13. 3 个「1」和 5 个「0」组成的 8 位补码的最小值
由 3 个「1」和 5 个「0」组成的 8 位二进制补码，能表示的最小整数是？

A. $-126$　B. $-125$　C. $-32$　D. $-3$

**答案**：B（$-125$）

**解析**：8 位补码中，负数的数值 = $-2^7+\sum_{i=0}^{6}b_i2^i$。要使它**最小**：
1. 符号位必须为 1（否则是非负数），用掉 1 个「1」；
2. 剩下的 2 个「1」放在权值**最低**的两位 $2^0,2^1$，让「正数补充项」尽量小：数值 $=-128+2+1=-125$。
编码即 `1000 0011`。若把剩下两个 1 放在高位（如 $b_6,b_5$）得 $-32$，反而更大——这是最典型的错误直觉。

**第一性考点**
- **本质**：补码是把「负数」映射到 $[0,2^n)$ 的**循环编码**；同一个位模式，负数一侧的绝对值 = $2^n-$（无符号值）。
- **判据**：补码求最小负值 ⇒ 符号位置 1，其余「1」优先放**低位**；求最大正值 ⇒ 符号位 0，其余「1」优先放高位。
- **迁移**：这条判据直接解释「补码能多表示一个负数」「$-128$ 无对应正数」、符号扩展（补 1 不补 0）以及溢出判定（同号相加变号即溢出）。

### 14. 浮点数加减运算的叙述
Ⅰ 对阶操作不会引起阶码上溢或下溢
Ⅱ 右规和尾数舍入都可能引起阶码上溢
Ⅲ 左规时可能引起阶码下溢
Ⅳ 尾数溢出时结果不一定溢出

A. 仅Ⅱ、Ⅲ　B. 仅Ⅰ、Ⅱ、Ⅳ　C. 仅Ⅰ、Ⅲ、Ⅳ　D. Ⅰ、Ⅱ、Ⅲ、Ⅳ

**答案**：D

**解析**：
- Ⅰ 对：对阶是「小阶向大阶看齐」，阶码只**增大**且以较大阶为目标，不会超过已合法的较大阶，故不上溢、也不下溢。
- Ⅱ 对：右规发生在尾数运算溢出时——尾数右移 1 位、阶码 $+1$，若阶码已到最大值则上溢；尾数舍入（如「0 舍 1 入」进位使尾数再次溢出）也会触发再右规，同样可能上溢。
- Ⅲ 对：左规时尾数左移 1 位、阶码 $-1$，阶码可能跌到最小值以下 ⇒ 下溢（按机器数 0 处理）。
- Ⅳ 对：尾数溢出只是「结果的真值超出尾数位宽」，通过右规把阶码加 1 后可能仍在表示范围内，因此尾数溢出**不一定**意味着结果溢出。

**第一性考点**
- **本质**：浮点运算的每一步都在动「阶码 + 尾数」这一对，**任何使阶码单调偏移的操作都可能把阶码推出范围**。
- **判据**：把四个动作按「阶码变化方向」列表——对阶（小阶↑，到较大阶为止）、右规（阶码↑）、左规（阶码↓）、舍入（可能使尾数进位再右规，阶码↑）。方向对了，溢出可能性自然清楚。
- **迁移**：IEEE 754 的「上溢→±∞、下溢→非规格化/0」、舍入模式的实现，都是这条「阶码单调性」的直接后果。

### 15. 直接映射 Cache 的总容量
主存地址 32 位、按字节编址，主存与 Cache 采用直接映射，主存块大小 4 个字，每字 32 位，回写（Write Back）方式。能存放 4K 字数据的 Cache 总容量至少是多少位？

A. 146K　B. 147K　C. 148K　D. 158K

**答案**：C（148K 位）

**解析**：
1. 块大小 $=4\times32=128$ 位 $=16$B ⇒ 块内地址 $=\log_2 16=4$ 位。
2. Cache 数据量 $=4\text{K}\times32=128\text{K}$ 位 $=16$KB ⇒ 行数 $=16\text{KB}/16\text{B}=1024=2^{10}$ 行 ⇒ 行号（直接映射的索引）10 位。
3. 主存地址 32 位 ⇒ tag $=32-10-4=18$ 位。
4. 每行附加位：tag 18 + 有效位 1 + 脏位 1（回写必须有脏位）= 20 位；数据 128 位 ⇒ 每行 148 位。
5. 总容量 $=1024\times148=148$K 位。

**第一性考点**
- **本质**：Cache 容量 = **数据 + 标签开销**，标签位数由「地址怎么切」决定：块内地址 → 行号 → tag。
- **判据**：切地址的顺序固定为「块内 → 索引 → tag」；写策略若为**回写**必须加 1 位脏位（直写不需要），这是本题唯一的额外项。
- **迁移**：全相联（无索引，tag = 地址 − 块内）、组相联（索引为组号）只是把「行号」换成「组号」，切法不变；命中率、平均访问时间题都先做这一步切分。

### 16. 一条 add 指令至少访问主存的次数
编译器把 `x=x+3;` 译为 `add xaddr, 3`，`xaddr` 是 x 的存储单元地址。机器采用页式虚拟存储、配有 TLB，Cache 为直写（Write Through）。完成该指令功能至少需要访问主存多少次？

A. 0　B. 1　C. 2　D. 3

**答案**：B

**解析**：「至少」意味着**所有能命中的都命中**：
- **取指令**：指令在 Cache 中命中、页表项在 TLB 中命中 ⇒ 0 次主存访问；
- **取/写操作数**：`x` 所在数据块也在 Cache 中命中 ⇒ 访问数据本身 0 次主存访问；但因为 Cache 采用**直写**，写命中时要**同时写入 Cache 与主存**，这一次主存写无法避免 ⇒ 1 次。
- 页表访问已被 TLB 命中消除，不额外算。

合计 1 次。

**第一性考点**
- **本质**：数「主存访问次数」= 数**遍历失效的层级**：TLB 命中省掉页表访存，Cache 命中省掉数据访存，但**写策略决定是否强制回写主存**。
- **判据**：直写（Write Through）⇒ 每次写都落到主存，命中也要 +1；回写（Write Back）⇒ 仅脏块替换时才写主存，题问「至少」时可为 0。
- **迁移**：把「TLB/Cache/写策略」三个开关做成表，任何「至少/至多访问主存次数」题逐层代入即得，不用背具体数字。

### 17. 需要周期性刷新的存储器
下列存储器中，在工作期间需要周期性刷新的是？

A. SRAM　B. SDRAM　C. ROM　D. FLASH

**答案**：B

**解析**：SDRAM（同步动态 RAM）用**电容**存电荷表示信息，电容会漏电，必须在电荷消失前周期性刷新（通常每 64ms 全阵列刷新一遍）。SRAM 用双稳态触发器存信息，通电即保持；ROM/FLASH 靠浮栅等非易失结构，断电仍保存，不需要刷新。

**第一性考点**
- **本质**：刷新需求的唯一来源是**存储元靠电荷暂存**（易失 + 会漏电），而不是「是不是 RAM」。
- **判据**：看到「电容存信息 ⇒ 必须刷新」；触发器（SRAM）、浮栅（FLASH）、熔丝（ROM）都不刷新。
- **迁移**：DRAM 的「行地址选通 + 刷新周期」是刷新控制器的由来；「刷新操作不需要 CPU 参与」也是本题常考的延伸点。

### 18. 4 体交叉编址存储器的访存冲突
某计算机使用 4 体交叉编址存储器，主存地址序列为 8005，8006，8007，8008，8001，8002，8003，8004，8000（十进制）。可能发生访存冲突的地址对是？

A. 8004 和 8008　B. 8002 和 8007　C. 8001 和 8008　D. 8000 和 8004

**答案**：D

**解析**：多体交叉存储器按**地址对体数取模**分体：体号 = 地址 mod 4。把序列换算成体号：
$$8005\to1,\;8006\to2,\;8007\to3,\;8008\to0,\;8001\to1,\;8002\to2,\;8003\to3,\;8004\to0,\;8000\to0$$
得到体号序列 $1,2,3,0,1,2,3,0,0$。冲突发生在**相邻两次访问落到同一个体**时（同一体在同一时刻只能服务一个请求）：序列尾部 $8004\to0$、紧接着 $8000\to0$，两者同体且相邻 ⇒ 冲突 D。
校验其他项：8004 与 8008 同体（都是 0）但相隔 5 个位置；8002 与 8007 体号 2、3 不同体；8001 与 8008 体号 1、0 不同体。

**第一性考点**
- **本质**：交叉存储器的带宽来自「**连续地址分散到不同体，可并行启动**」；冲突就是「两个请求挤到同一个体」。
- **判据**：先算体号 = 地址 mod 体数，再检查**访问序列中相邻项**是否同体；只有相邻（同一总线周期组内）才冲突。
- **迁移**：只要地址差是体数的整数倍且落在连续请求里，就会退化；这也是「按字编址 vs 按字节编址」必须换算的原因（字节编址时体号 = 字节地址 div 编址单位 mod 体数）。

### 19. 总线定时的错误叙述
下列有关总线定时的叙述中，错误的是？

A. 异步通信方式中，全互锁协议最慢
B. 异步通信方式中，非互锁协议的可靠性最差
C. 同步通信方式中，同步时钟信号可由各设备提供
D. 半同步通信方式中，握手信号的采样由同步时钟控制

**答案**：C

**解析**：同步通信的全部设备必须共用**同一个系统时钟**，由总线时钟发生器统一提供；若各设备各自提供时钟，就是「异步」而不再是同步。A、B、D 均正确：全互锁要求请求/回答双方都确认，握手次数最多最慢；非互锁只单向发请求，最不可靠；半同步 = 「同步时钟采样 + 异步握手信号」，兼具两者。

**第一性考点**
- **本质**：总线定时的分类标准是**「谁来定传输的时刻」**：时钟（同步）还是握手（异步）还是两者混合（半同步）。
- **判据**：「同步」⇒ 时钟必须统一且全总线一个源；出现「各设备自己给时钟」一定错。
- **迁移**：三类定时的速度/可靠性排序固定为「同步最快但只适合短距同速设备；异步最可靠但慢；半同步折中」，记排序比记协议名有用。

### 20. 磁盘访问一个扇区的平均存取时间
磁盘转速 7200 转/分，平均寻道时间 8ms，每磁道 1000 个扇区。访问一个扇区的平均存取时间约为？

A. 8.1ms　B. 12.2ms　C. 16.3ms　D. 20.5ms

**答案**：B

**解析**：
1. 旋转一周时间 $T=\dfrac{60\text{s}}{7200}=8.33$ms；
2. 平均旋转延迟 = 半周 $=4.17$ms；
3. 传输一个扇区 $=\dfrac{8.33}{1000}=0.0083$ms；
4. 平均存取时间 $=8+4.17+0.008\approx12.18$ms ⇒ 12.2ms。

**第一性考点**
- **本质**：磁盘访问时间 = **寻道（机械臂）+ 旋转延迟（盘片）+ 传输（位流）**，三者量级依次相差一个数量级。
- **判据**：「平均寻道」直接用给定值；「平均旋转延迟」永远取**半周**（除非题给最坏情况）；「传输时间」按扇区占比算。
- **迁移**：扇区数变大 ⇒ 传输时间变小但寻道/旋转不变，所以「提高扇区密度」改善的是传输不是寻道；RAID、磁盘调度题的量化基础都是这三个分量。

### 21. 中断 I/O 方式下 CPU 与端口交换的信息
在采用中断 I/O 方式控制打印输出的情况下，CPU 和打印控制接口中的 I/O 端口之间交换的信息不可能是？

A. 打印字符　B. 主存地址　C. 设备状态　D. 控制命令

**答案**：B

**解析**：中断 I/O 是**程序控制的数据传送**：CPU 执行指令把字符送到端口数据寄存器（打印字符）、读状态寄存器（设备状态）、写控制寄存器（启动/停止等控制命令）。**主存地址**是 DMA 方式才需要交给设备的信息（DMA 控制器据此直接读写主存），中断方式下数据搬运仍由 CPU 用指令完成，不需要把主存地址给端口。

**第一性考点**
- **本质**：区分 I/O 方式的判据是**「数据通路是否绕过 CPU」**：程序查询/中断 I/O 走 CPU 寄存器，DMA 走设备与主存直连。
- **判据**：题目出现「主存地址/内存首址/传送长度交给设备」⇒ 一定是 DMA 的特征，中断方式没有。
- **迁移**：由此可推出「中断方式每传一个字都要一次中断（开销 ≈ 几十条指令）」而 DMA 只需首尾两次中断，这正是 DMA 效率高的原因。

### 22. 内部异常（内中断）的错误叙述
内部异常分为故障（fault）、陷阱（trap）、终止（abort）。下列叙述错误的是？

A. 内部异常的产生与当前执行指令相关
B. 内部异常的检测由 CPU 内部逻辑实现
C. 内部异常的响应发生在指令执行过程中
D. 内部异常处理后返回到发生异常的指令继续执行

**答案**：D

**解析**：三类异常的**返回点不同**：故障（如缺页、除数为 0、非法操作码）在指令执行中检测到，处理后**重新执行该指令**；陷阱（如系统调用、断点）在指令执行**结束后**响应，返回**下一条指令**；终止（如硬件故障、RAM 校验错）**不返回**，直接终止进程。因此「处理后返回到发生异常的指令继续执行」只适用于故障，不能概括内中断 ⇒ D 错。A、B、C 均对：内中断由 CPU 内部在指令执行过程中检测，与当前指令相关。

**第一性考点**
- **本质**：内中断与外中断的分水岭不在「谁引发」，而在**「与当前指令是否同步」**：内中断是当前指令的执行结果，外中断是 CPU 外部的随机事件。
- **判据**：返回点决定类别——重执行原指令 = fault，执行下一条 = trap，不返回 = abort；与之相对，外中断总在**指令执行结束后**响应并返回下一条。
- **迁移**：缺页处理必须能「重新执行原指令」才正确，所以页故障属于 fault；系统调用要返回下一条，所以属于 trap。这条判据直接决定中断处理程序怎么保存断点。

### 23. 处理外部中断时由操作系统保存的内容
处理外部中断时，应该由操作系统保存的是？

A. 程序计数器（PC）的内容
B. 通用寄存器的内容
C. 块表（TLB）中的内容
D. Cache 中的内容

**答案**：B

**解析**：中断响应由**硬件**完成「关中断、保存断点（PC）、引出中断服务程序」；进入服务程序后，**操作系统/软件**负责保存**通用寄存器等现场信息**（否则服务程序用完寄存器会破坏原程序状态）。TLB 与 Cache 的内容是硬件自动维护的存储层次，中断现场不需要也不应该由 OS 保存。

**第一性考点**
- **本质**：中断现场保护的分工是**「硬件保存最少的必要断点，软件保存其余现场」**——硬件只保存 PC（和 PSW），多存会拖慢所有中断。
- **判据**：「由硬件保存」⇒ 断点 PC、PSW；「由操作系统保存」⇒ 通用寄存器、被破坏的临时状态。
- **迁移**：这个分工决定了中断响应是「几个机器周期」，而现场保护是「若干条指令」；中断开销估算、中断隐指令的内容都从这里推。

### 24. 不可能导致用户态转内核态的指令
下列指令已装入指令寄存器，执行时不可能导致 CPU 从用户态变为内核态的是？

A. `DIV R0,R1`　B. `INT n`　C. `NOT R0`　D. `MOV R0,addr`

**答案**：C

**解析**：用户态→内核态的触发途径只有三类：**中断/异常**、**陷入（trap，如 `INT n`）**、**执行特权指令**。
- `DIV R0,R1`：除数为 0 时产生内部异常（故障）⇒ 进内核态处理 ✓
- `INT n`：软中断/系统调用指令，直接陷入内核 ✓
- `MOV R0,addr`：访存时可能缺页（页故障）或地址越界 ⇒ 进内核态 ✓
- `NOT R0`：纯寄存器逻辑运算，不访存、不产生异常、非特权指令 ⇒ 不可能切换 ✗

**第一性考点**
- **本质**：态切换的唯一入口是**「控制权交给内核代码」**，而交出控制权只能靠中断/异常/陷入。
- **判据**：判断一条指令能否引发态切换 ⇒ 看它是否会**访存、产生异常或本身是陷入/特权指令**；纯寄存器运算一定不能。
- **迁移**：由此推出「用户态程序无法自己提权」——必须通过系统调用这一唯一受控入口，这是 OS 保护机制的核心。

### 25. 进程由执行态变为就绪态的事件
下列选项中，会导致进程从执行态变为就绪态的事件是？

A. 执行 P(wait) 操作　B. 申请内存失败　C. 启动 I/O 设备　D. 被高优先级进程抢占

**答案**：D

**解析**：三态模型中，**执行→就绪**只有一个原因：**CPU 被夺走但进程本身仍可运行**，即时间片用完或被更高优先级进程抢占（D）。其余三项都让进程**等资源**：执行 P 操作（A）若信号量不足则进入阻塞；申请内存失败（B）等内存而阻塞；启动 I/O（C）等 I/O 完成而阻塞。阻塞态与就绪态的分界是「**还缺不缺资源**」。

**第一性考点**
- **本质**：状态迁移只看两件事——**「CPU 在不在它手上」和「资源够不够」**：缺 CPU = 就绪，缺资源 = 阻塞，两者都有 = 正常执行。
- **判据**：凡「被动失去 CPU 但不需要等资源」⇒ 执行→就绪（抢占、时间片完）；凡「主动等资源/等事件」⇒ 执行→阻塞（P 操作、I/O 请求、申请失败）。
- **迁移**：I/O 完成是**阻塞→就绪**（不是→执行），被唤醒的进程还要排队等调度；这条区分是判断题的高频陷阱。

### 26. 死锁避免与死锁检测的比较
系统 S1 采用死锁避免方法，S2 采用死锁检测方法。下列叙述正确的是？
Ⅰ．S1 会限制用户申请资源的顺序，而 S2 不会
Ⅱ．S1 需要进程运行所需资源总量信息，而 S2 不需要
Ⅲ．S1 不会给可能导致死锁的进程分配资源，而 S2 会

A. 仅Ⅰ、Ⅱ　B. 仅Ⅱ、Ⅲ　C. 仅Ⅰ、Ⅲ　D. Ⅰ、Ⅱ、Ⅲ

**答案**：B

**解析**：
- Ⅰ 错：**限制申请顺序**是死锁**预防**中「资源有序分配法」的做法；死锁避免（银行家算法）不限制顺序，只在每次分配前做安全性检查。
- Ⅱ 对：银行家算法必须预先知道每个进程的**最大资源需求**（总量信息）才能判断「分配后是否仍存在安全序列」；检测算法只看当前**资源分配图/需求矩阵**，不需要总量声明。
- Ⅲ 对：避免 = 「分配前试算，会让系统进入不安全态就不分配」；检测 = 「先分配，再周期性查有没有环（死锁）」，故 S2 会给出可能致死的分配。

**第一性考点**
- **本质**：四个策略的差别在**「介入时机」**：预防（破坏必要条件，事前）→ 避免（分配前试算，事中）→ 检测+恢复（分配后定期查，事后）→ 忽略（鸵鸟）。
- **判据**：出现「资源总量 / 最大需求 / 安全序列」⇒ 死锁避免；出现「资源分配图 / 化简 / 环路」⇒ 死锁检测；出现「一次性申请 / 有序申请 / 剥夺」⇒ 死锁预防。
- **迁移**：「安全状态 ≠ 无死锁」：安全状态一定无死锁，不安全状态**可能**死锁（不是必然）；银行家算法只能保证安全，不能提高利用率。

### 27. LRU 算法的淘汰页
系统为某进程分配 4 个页框，已访问页号序列 2,0,2,9,3,4,2,8,2,4,8,4,5。下一页访问页号 7 时，依据 LRU 算法应淘汰的页号是？

A. 2　B. 3　C. 4　D. 8

**答案**：A（页号 2）

**解析**：4 个页框，逐步推演（按「最近使用」到「最久未使用」排列）：
| 访问 | 页框状态（左=最久未用） | 说明 |
|---|---|---|
| 2 | 2 | 装入 |
| 0 | 2,0 | 装入 |
| 2 | 0,2 | 命中 |
| 9 | 0,2,9 | 装入 |
| 3 | 0,2,9,3 | 装入（满） |
| 4 | 2,9,3,4 | 淘汰 0 |
| 2 | 9,3,4,2 | 命中 |
| 8 | 3,4,2,8 | 淘汰 9 |
| 2 | 3,4,8,2 | 命中 |
| 4 | 3,8,2,4 | 命中 |
| 8 | 3,2,4,8 | 命中 |
| 4 | 3,2,8,4 | 命中 |
| 5 | 2,8,4,5 | 淘汰 3 |

此时最久未使用的是页 2 ⇒ 访问 7 时淘汰 2。

**第一性考点**
- **本质**：LRU 依赖「**时间局部性**」——最近用过的还要用，最久没用的最可能不再用；实现上等价于维护一个「最近使用顺序」队列。
- **判据**：每次访问都把该页提到「最近使用」端；**命中也要提**（最后两步 8、4 连续命中，顺序仍在变），这是最容易漏的。
- **迁移**：与 FIFO（按装入顺序淘汰，与命中无关）对照记忆；Belady 异常只发生在 FIFO；LRU 是栈式算法，页框增多命中率单调不降。

### 28. 系统内存中设置磁盘缓冲区的目的
在系统内存中设置磁盘缓冲区的主要目的是？

A. 减少磁盘 I/O 次数
B. 减少平均寻道时间
C. 提高磁盘数据可靠性
D. 实现设备无关性

**答案**：A

**解析**：内存缓冲区把多个小 I/O 合并成一个大 I/O（写缓冲）、或把读到的相邻块预取（读缓冲），从而**减少实际磁盘 I/O 次数**。缓冲区在内存里，不改变磁头移动路径 ⇒ 不减少寻道时间；不冗余存储 ⇒ 不提高可靠性；设备无关性由抽象接口/驱动层实现，不是缓冲区的目的。

**第一性考点**
- **本质**：缓冲（buffer）解决的是**速度不匹配 + 传输粒度不匹配**，其收益体现在「次数」上，不体现在「单次时间」上。
- **判据**：问缓冲区作用 ⇒ 答「减少 I/O 次数 / 平滑速度差异 / 合并小请求」；问「减少寻道」⇒ 那是磁盘调度算法（SCAN 等）的职责。
- **迁移**：SPOOLing 是「用磁盘模拟独占设备」的缓冲技术，同理不改寻道；缓冲 vs 缓存（cache）的区别是「缓冲为了匹配速度，缓存为了复用数据」。

### 29. 索引节点读文件需访问的磁盘块数
索引节点中存直接索引指针 10 个、一级和二级索引指针各 1 个；磁盘块 1KB，每个指针 4 字节；索引节点已在内存。读偏移量 1234 和 307400 处所在磁盘块，需访问的磁盘块数分别是？

A. 1,2　B. 1,3　C. 2,3　D. 2,4

**答案**：B（1，3）

**解析**：每块可存指针 $1024/4=256$ 个。
- 直接索引覆盖前 10 块：$0\sim10239$ 字节。偏移 1234 落在直接索引范围 ⇒ 只需读 1 个数据块 = **1 次**。
- 一级索引覆盖 $10240\sim 10240+256\times1024-1=272383$ 字节。307400 已超出 ⇒ 需走二级索引。二级索引的组织是「一级索引块 → 指向二级索引块 → 指向数据块」，读取路径要**先读一级索引块、再读二级索引块、最后读数据块** = **3 次**（索引节点本身已在内存，不计）。

**第一性考点**
- **本质**：多级索引是**用指针层数换文件最大长度**，访问代价 = 1（数据块）+ 经过的索引块层数。
- **判据**：先算每层容量（指针数 × 块大小），从直接索引往外逐层比对偏移量；落在第 $k$ 级 ⇒ 访问次数 = $k+1$。
- **迁移**：求「文件最大长度」时把每层容量相加（10 + 256 + 256²）× 1KB；UNIX inode 的 12 直接 + 单/双/三间接就是本模型，mix 题只需换数字。

### 30. 不能组合使用的页面分配与置换策略
在请求分页系统中，页面分配策略与页面置换策略不能组合使用的是？

A. 可变分配，全局置换
B. 可变分配，局部置换
C. 固定分配，全局置换
D. 固定分配，局部置换

**答案**：C

**解析**：**固定分配**意味着每个进程的页框数固定，而**全局置换**允许从其它进程的页框中淘汰一页——这必然改变「被淘汰进程」的页框数，与「固定分配」自相矛盾。故「固定分配 + 全局置换」不可组合。其余三种组合都自洽：固定+局部（各进程只在自身页框内换）、可变+全局（按缺页率调整并全局抢框）、可变+局部。

**第一性考点**
- **本质**：两种策略的冲突点是**「页框数是否可变」**：分配策略规定页框数的确定方式，置换策略规定淘汰时的候选范围。
- **判据**：固定分配要求「我的页框只归我」，全局置换允许「别人的页框也能抢」⇒ 二者互斥。
- **迁移**：工作集模型解释「可变分配 + 全局置换」为何要监控缺页率来调页框数；抖动（thrashing）的成因正是全局置换把页框抢到不够用。

### 31. 位图法释放盘块要修改的位
文件系统用位图表示磁盘空间，位图存于 32～127 号块，每块 1024 字节，盘块与块内字节均从 0 开始编号。要释放盘块号 409612，位图中要修改的位所在盘块号和块内字节序号是？

A. 81、1　B. 81、2　C. 82、1　D. 82、2

**答案**：C（82、1）

**解析**：每块装 $1024\times8=8192$ 位，即每块位图管理 8192 个盘块。
1. 相对位号 $=409612$，块序号 $=\lfloor 409612/8192\rfloor=50$（$50\times8192=409600$，余 12）。
2. 位图是从 32 号块开始的第 0 块 ⇒ 实际盘块号 $=32+50=82$。
3. 块内偏移 12 位 ⇒ 字节序号 $=\lfloor12/8\rfloor=1$，位序号 $=12\bmod 8=4$。

故为 82 号块、块内第 1 号字节（第 4 位）。

**第一性考点**
- **本质**：位图是**「一位管一块」的混合进制换算**：盘块号 →（÷ 每块位数）块号 +（mod）位号 →（÷ 8）字节 +（mod 8）位。
- **判据**：三处进制必须逐层取商取余，且**位图起始盘块号要加回去**（本题的坑就是 32 这个偏移）。
- **迁移**：FAT 表、索引块、页表项的「第几项在第几块第几字节」全是同一换算；「块内字节序号从 0 开始」时不要再 +1。

### 32. SCAN 调度磁头移过的磁道数
某硬盘 200 个磁道（最外侧磁道号 0），请求序列 130,42,180,15,199，当前磁头在 58 号磁道并向内侧移动。按 SCAN 调度处理完请求后，磁头移过的磁道数是？

A. 208　B. 287　C. 325　D. 382

**答案**：C（325）

**解析**：SCAN（电梯算法）沿当前方向一直走到该方向**端点**，再反向。磁道号增大 = 向内侧。
1. 向内侧：$58\to130$（72）$\to180$（50）$\to199$（19），到最内端 199 后反向；
2. 向外侧：$199\to42$（157）$\to15$（27），15 是最外侧请求，处理完即停。

总移动 $=72+50+19+157+27=325$ 磁道。

**第一性考点**
- **本质**：磁盘调度算法比较的是**磁头总移动量**，等价于「排序 + 单向扫描」；SCAN 的关键是**必须走到端点**而不是最远请求。
- **判据**：总移动 = 当前→方向端点的距离 + 端点→反向最远请求的距离（按请求排序后分段累加）。
- **迁移**：C-SCAN 只单向服务、回程不服务（回程距离照算）；SSTF 每次选最近，可能出现饥饿。三者都可以用「排序后分段累加」核算。

### 33. POP3 使用的传输层服务
通过 POP3 协议接收邮件时，使用的传输层服务类型是？

A. 无连接不可靠的数据传输服务
B. 无连接可靠的数据传输服务
C. 有连接不可靠的数据传输服务
D. 有连接可靠的数据传输服务

**答案**：D

**解析**：POP3 是**应用层**的邮件读取协议，其下层固定使用 **TCP**：TCP 面向连接（三次握手）、提供可靠传输（确认重传、按序交付）。故为「有连接、可靠」的数据传输服务。

**第一性考点**
- **本质**：传输层服务的四象限由「是否连接」×「是否可靠」划分，**TCP = 有连接可靠，UDP = 无连接不可靠**（另两象限在现实中基本不用）。

### 34. 两种编码方案（**题面含图 · 待核验**）

A. NRZ 和曼彻斯特编码
B. NRZ 和差分曼彻斯特编码
C. NRZI 和曼彻斯特编码
D. NRZI 和差分曼彻斯特编码

**答案**：A

**解析**：四种编码的判读要点：
- **NRZ（不归零）**：一个比特周期内电平保持不变，`0` 与 `1` 各对应一个固定电平（本题按「1 高、0 低」读），**比特边界处才可能变电平**。
- **NRZI（不归零反转）**：看**边界处是否跳变**表示 1，电平本身不直接对应 0/1。
- **曼彻斯特编码**：**每个比特周期中间必有跳变**（自同步），跳变方向表示 0/1。
- **差分曼彻斯特编码**：**比特开始处**有无跳变表示 0/1，**中间仍然必跳变**（用来提取时钟）。

底本波形中编码 1 没有中间的固定跳变、编码 2 每个比特中间都有跳变，且起始处规律符合曼彻斯特 ⇒ 答案 A。

> ⚠ 待核对：波形图本身在底本中为图片，本机无视觉通道，无法复算波形细节。已逐条核对官方答案页为 A；请对照底本 P4 的波形图复核「编码 2 是否每比特中间必跳变」。

**第一性考点**
- **本质**：编码题只问两件事——**「0/1 用什么区分」和「有没有自带时钟（自同步）」**。曼彻斯特类靠中间跳变同步，NRZ 类不自同步。
- **判据**：先数「每比特是否必有跳变」：有 ⇒ 曼彻斯特族；再看跳变发生在「中间」还是「起始处」⇒ 普通/差分。无固定中间跳变 ⇒ NRZ 族，再看是电平表示还是边界跳变表示 ⇒ NRZ/NRZI。
- **迁移**：编码效率 = 1（NRZ）、0.5（曼彻斯特）、1（4B/5B 前）；曼彻斯特带宽需求翻倍但自带同步，这正是以太网（10BASE-T）选它的原因。

### 35. 滑动窗口协议的帧序号位数
主机甲通过 128kbps 卫星链路、采用滑动窗口协议向乙发送数据，链路单向传播延迟 250ms，帧长 1000 字节，不考虑确认帧开销。为使链路利用率不小于 80%，帧序号的比特数至少是？

A. 3　B. 4　C. 7　D. 8

**答案**：B（4 位）

**解析**：
1. 一帧的发送时延 $T_f=\dfrac{1000\times8}{128\times10^3}=0.0625$s $=62.5$ms。
2. 往返时延 $\text{RTT}=2\times250=500$ms；从开始发一帧到收到其确认需 $T_f+\text{RTT}=562.5$ms。
3. 采用**流水线（窗口）**后，这 $562.5$ms 内可连续发出 $W$ 帧，利用率
$$U=\frac{W\cdot T_f}{T_f+\text{RTT}}\ \ge\ 0.8\ \Rightarrow\ W\ \ge\ \frac{0.8\times562.5}{62.5}=7.2$$
取整 $W\ge8$。
4. 用 $n$ 位序号时，为保证不混淆新旧帧，窗口上限为 $W\le 2^n-1$（选择重传/后退 N 帧的通用约束）；需 $2^n-1\ge8\Rightarrow n=4$（此时 $W\le15\ge8$）。

**第一性考点**
- **本质**：窗口协议的本质是**「用允许在途的帧数把传播时延‘填满’」**，利用率就是「发送时间 / 发送+等待」的占比。
- **判据**：先算 $W\ge U(T_f+\text{RTT})/T_f$，再由 $2^n-1\ge W$ 定序号位数；「不考虑确认帧开销」意味着 $T_{ack}=0$，不要多加。
- **迁移**：卫星链路延迟大 ⇒ 需要大窗口（本题 500ms RTT 使窗口吃到 8 帧）；换成 1000km 光纤就只要几位。GBN 与 SR 的窗口上限差别（$2^n-1$ vs $2^{n-1}$）是同一约束的两种用法。

### 36. CSMA/CD 协议的错误叙述
下列关于 CSMA/CD 协议的叙述中，错误的是？

A. 边发送数据帧，边检测是否发生冲突
B. 适用于无线网络，以实现无线链路共享
C. 需要根据网络跨距和数据传输速率限定最小帧长
D. 当信号传播延迟趋近 0 时，信道利用率趋近 100%

**答案**：B

**解析**：CSMA/CD 的名字就说明了它的前提——**冲突可以被「边发边听」检测到**，这要求共享介质的信号能双向传播、且冲突造成的波形畸变可被发端感知，因此适用于**有线（总线型以太网、双绞线半双工）**。无线环境存在隐藏终端、且发送时无法有效监听自身信号叠加的冲突，所以无线局域网用 **CSMA/CA（避免而非检测）**。A、C、D 均对：最小帧长须保证「发送时间 ≥ 2τ」，使发送方在最远端的冲突信号回来前仍在发送；τ→0 时冲突窗口消失，利用率趋近 100%。

**第一性考点**
- **本质**：CSMA/CD 的可行性条件是**「冲突能在发送期间被检测到」**，最小帧长 $L/v\ge2\tau$ 正是把这个条件量化。
- **判据**：看到「无线」⇒ 必为 CSMA/CA（避免）；看到「最小帧长 / 2τ / 冲突窗口」⇒ 必为 CSMA/CD。
- **迁移**：最小帧长由「跨距 × 速率」共同决定——速率升高或跨距增大都要**加长最小帧**或缩短跨距，这是以太网从 10M 到千兆升级时的真实约束。

### 37. 关于以太网交换机的正确叙述
下列关于交换机的叙述中，正确的是？

A. 以太网交换机本质上是一种多端口网桥
B. 通过交换机互连的一组工作站构成一个冲突域
C. 交换机每个端口所连网络构成一个独立的广播域
D. 以太网交换机可实现采用不同网络层协议的网络互联

**答案**：A

**解析**：交换机工作在数据链路层，逐帧查 MAC 表转发，本质就是**多端口的网桥**（A 对）。每个端口是**独立的冲突域**（B 错，互连的工作站分属不同冲突域，不再共享介质）；但所有端口默认属于**同一个广播域**（C 错，广播域要由路由器或 VLAN 划分）；互联不同网络层协议的网络是**路由器/三层设备**的职责（D 错）。

**第一性考点**
- **本质**：二层设备（网桥/交换机）**隔离冲突域、不隔离广播域**；三层设备（路由器）**隔离广播域**。
- **判据**：数「冲突域」看**端口数/网段**，数「广播域」看**路由器/VLAN 边界**；交换机端口数增加只增冲突域个数，不增广播域。
- **迁移**：集线器（物理层）所有端口同一冲突域且同一广播域；VLAN 让一台交换机划出多个广播域——这是交换机能力的延伸而非改变其层次。

### 38. 路由表的最长前缀匹配
路由表含：`169.96.40.0/23 → S1`、`169.96.40.0/25 → S2`、`169.96.40.0/27 → S3`、`0.0.0.0/0 → S4`。收到目的地址 169.96.40.5 的 IP 分组，转发接口是？

A. S1　B. S2　C. S3　D. S4

**答案**：C（S3）

**解析**：目的地址 169.96.40.5 同时落在三条具体路由内（/23、/25、/27），按**最长前缀匹配**取前缀最长的 /27：其地址范围是 $169.96.40.0\sim169.96.40.31$，包含 .5 ⇒ 走 S3。默认路由 0.0.0.0/0 只在其它都不匹配时使用。

### 39. 拥塞控制下 4 个 RTT 后的发送窗口
甲、乙新建 TCP 连接，甲拥塞控制初始阈值 32KB，MSS=1KB，甲始终有数据发送；乙分配 16KB 接收缓存且对每个数据段确认，忽略传输延迟，乙收到的数据全部留在缓存不取走。甲未超时，经过 4 个 RTT 后甲的发送窗口是？

A. 1KB　B. 8KB　C. 16KB　D. 32KB

**答案**：A（1KB）

**解析**：慢开始阶段每 RTT 拥塞窗口翻倍，同时**接收窗口随乙的缓存被占满而收缩**，发送窗口 $=\min(\text{cwnd},\text{rwnd})$：

| RTT | cwnd 起点 | 本 RTT 发送量 | 累计已发 | 乙剩余缓存 rwnd | 下个窗口 |
|---|---:|---:|---:|---:|---:|
| 1 | 1KB | 1KB | 1KB | 15KB | min(2,15)=2 |
| 2 | 2KB | 2KB | 3KB | 13KB | min(4,13)=4 |
| 3 | 4KB | 4KB | 7KB | 9KB | min(8,9)=8 |
| 4 | 8KB | 8KB | 15KB | 1KB | **min(16,1)=1KB** |

4 个 RTT 后剩余缓存只有 1KB ⇒ 发送窗口被接收窗口卡到 1KB。注意：虽然 cwnd 已到 16KB（未达阈值 32KB，仍在慢开始），但**发送窗口取两者较小值**。

**第一性考点**
- **本质**：发送窗口 = **拥塞控制与流量控制的交集**；两条约束谁更紧谁说了算。
- **判据**：先按「每 RTT 翻倍」推进 cwnd（慢开始），同时按「已发字节累计」扣减 rwnd；窗口取 min。
- **迁移**：本题的「不取走缓存」是刻意让 rwnd 成为瓶颈（零窗口之前先卡到 1KB）；若乙及时取走，4 RTT 后窗口就是 cwnd=16KB（**C 是陷阱**）。

### 40. HTTP 请求报文的错误解读
某浏览器发出的 HTTP 请求报文：`GET /index.html HTTP/1.1`、`Host: www.test.edu.cn`、`Connection: Close`、`Cookie: 123456`。下列叙述错误的是？

A. 该浏览器请求浏览 index.html
B. index.html 存放在 www.test.edu.cn 上
C. 该浏览器请求使用持续连接
D. 该浏览器曾经浏览过 www.test.edu.cn

**答案**：C

**解析**：`Connection: Close` 明确表示**本次响应后关闭连接**，即请求使用**非持续连接**；要使用持续连接应写 `Connection: keep-alive`（HTTP/1.1 默认 keep-alive，但显式 Close 会覆盖）。A 对（GET 路径为 /index.html）、B 对（Host 指明目标主机）、D 对（请求携带 Cookie，说明此前访问过该站点并拿到过 cookie）。

**第一性考点**
- **本质**：HTTP 报文头是**会话行为的开关**：`Connection` 管连接复用，`Host` 管虚拟主机定位，`Cookie` 管状态保持。
- **判据**：`Connection: Close` ⇒ 每个对象一个 TCP 连接（非持续）；缺省或 `keep-alive` ⇒ 持续连接（pipeline 还要额外条件）。
- **迁移**：持续连接把「多对象请求」从 $2RTT$ 每对象降到一次握手；HTTP/2 的多路复用又进一步消除了队头阻塞——这条演进主线都是从报文头这一个开关推出来的。

### 41.（15 分）单链表删除绝对值相等的重复结点
**题目与条件**：用单链表保存 $m$ 个整数，结点结构为 `[data][link]`，且 $|data|\le n$（$n$ 为正整数）。设计**时间复杂度尽可能高效**的算法：对链表中 `data` 绝对值相等的结点，仅保留第一次出现的结点，删除其余结点。要求：(1) 给出算法基本设计思想；(2) 用 C/C++ 给出结点类型定义；(3) 描述算法并注释；(4) 说明时间复杂度与空间复杂度。（**题面含图**：底本 P5 给出删除前后的链表示意，内容为示例，不影响算法。）

**解题思路**：题目同时给了两个强信号——「$|data|\le n$」是一个**值域很小的整数范围**，「时间尽可能高效」是要求。值域有限 + 要去重，识别信号指向**辅助数组做存在性标记**（用空间换时间）：一次遍历即可判定「绝对值是否已出现」，避免两两比较的 $O(m^2)$。

**逐步推导**：
1. 因为 $|data|\le n$，开一个大小为 $n+1$ 的辅助数组 `q`，初值全 0；`q[k]=1` 表示绝对值 $k$ 已出现过。
2. 用 `p` 指向当前结点的前驱，检查 `p->link` 的 `data` 的绝对值 $m$。
3. 若 `q[m]==0`：首次出现，标记 `q[m]=1`，保留该结点，`p` 后移。
4. 若 `q[m]==1`：重复出现，删掉 `p->link` 指向的结点（`r=p->link; p->link=r->link; free(r);`），`p` **不后移**（因为新的后继还没检查）。
5. 单趟扫描结束即完成；释放辅助数组。

```c
typedef struct node { int data; struct node *link; } NODE;
typedef NODE *PNODE;

void func(PNODE h, int n) {
    PNODE p = h, r;
    int *q = (int *)malloc(sizeof(int) * (n + 1));
    for (int i = 0; i <= n; i++) q[i] = 0;      // 辅助数组清零
    while (p->link != NULL) {
        int m = p->link->data > 0 ? p->link->data : -p->link->data;
        if (q[m] == 0) {                        // 首次出现：保留
            q[m] = 1;
            p = p->link;
        } else {                                // 重复出现：删除
            r = p->link;
            p->link = r->link;
            free(r);
        }
    }
    free(q);
}
```

**关键结论与适用条件**：时间 $O(m)$（$m$ 为结点数，一趟扫描）；空间 $O(n)$（辅助数组 $n+1$）。适用前提是**值域有界且已知**——若 $|data|$ 无上界，就不能用数组下标做标记，只能退化为 $O(m^2)$ 的两两比较或改用哈希表。

**易错点**：①删除结点时 `p` **不能**后移，否则漏检连续重复（如 `1,1,1`）；②`while (p->link != NULL)` 用的是前驱判断，不能写成 `p != NULL` 再去取 `p->link->link`；③绝对值的边界：`data` 可为 $-n$，故数组要开到 $n+1$（下标 0..n），不能开 $n$；④忘记 `free(q)` 与 `free(r)` 会泄漏内存；⑤若题目改为「绝对值相同的结点全部删除」，则需两趟（先计数再删）。

**第一性考点**
- **本质**：本题考的是**「用值域换时间」**——当 key 的取值范围可控时，数组下标就是最便宜的哈希。
- **判据**：题干出现「值域 ≤ n」「次数/时间尽可能高效」⇒ 开标记数组，把「是否出现过」变成 $O(1)$ 查表。
- **迁移**：位图（用 1 位代替 1 个 int）、计数排序、桶排序都是这一条；若 n 很大而 m 很小，则反转思路改用哈希表（以元素数为基准），本质仍是「按较小的那一维开空间」。

**变式自测**：若要求空间 $O(1)$ 且链表无序，最优时间复杂度是多少？<details>$O(m^2)$。没有辅助空间就无法 O(1) 判重，只能对每个结点扫描其后继（双重循环），时间 $O(m^2)$、空间 $O(1)$。若能改链表顺序，可先排序再删邻，但链表排序本身也是 $O(m\log m)$ 且需额外空间。</details>

**来源定位**：2015 408 第 41 题，底本 P5（题面）、P9–P10（官方解答与评分说明），fs_id 见 `01-来源与规范.md` 溯源表。

### 42.（8 分）图的邻接矩阵与矩阵幂的含义（**题面含图 · 部分待核验**）
**题目与条件**：已知含有 5 个顶点的图 $G$ 如底本 P5 图所示（顶点记 $0\sim4$）。回答：(1) 写出图 $G$ 的邻接矩阵 $A$（行列下标从 0 开始）；(2) 求 $A^2$，并说明 $A^2$ 中 0 行 3 列元素值的含义；(3) 若 $n$（$n\ge2$）个顶点的图邻接矩阵为 $B$，则 $B^m$（$2\le m\le n$）中非零元素的含义是什么？

**解题思路**：邻接矩阵的定义是 $A_{ij}=1$ 当且仅当存在边 $\langle i,j\rangle$（无向图对称，有向图不对称）。「长度为 $m$ 的路径条数」与「矩阵幂」的联系来自矩阵乘法的定义式 $A^2_{ij}=\sum_k A_{ik}A_{kj}$——每项恰是「$i\to k\to j$ 是否为一条长度为 2 的路径」，求和即计数。看到「$A^m$」就该条件反射到路径计数。

**逐步推导**：
1. 依图逐顶点读边，填 $A$：第 $i$ 行第 $j$ 列为 1 表示顶点 $i$ 到 $j$ 有边，否则 0。
2. 计算 $A^2=AA$，其中 $A^2_{ij}=\sum_{k=0}^{4}A_{ik}A_{kj}$。以 0 行 3 列为例：$A^2_{0,3}=\sum_k A_{0k}A_{k3}$，即枚举「从 0 出发的边 $0\to k$」与「$k\to3$ 的边」的公共中间点 $k$ 的个数。
3. 底本给出 $A^2_{0,3}=3$，含义是**从顶点 0 到顶点 3、长度为 2 的路径共有 3 条**。
4. 推广到 $A^m$：由归纳（或矩阵乘法结合律）可知 $A^m_{ij}$ = 从 $i$ 到 $j$、长度恰为 $m$ 的**路径条数**；非零即「至少存在一条长度为 $m$ 的通路」。

**关键结论与适用条件**：$A^m_{ij}$ = 长度恰为 $m$ 的路径条数（有向图按有向边计，无向图自动对称）。$m=1$ 时退化为邻接关系；$m$ 很大时应做快速幂或只关心「可达性」（此时把乘法改成布尔「与/或」得到可达矩阵 $A^*$，但**布尔矩阵的幂只表示可达，不再表示条数**）。

**易错点**：①把「长度为 $m$ 的路径」误答成「经过 $m$ 个顶点」（应经过 $m+1$ 个顶点、$m$ 条边）；②矩阵乘法用布尔运算会丢掉条数信息（本题问的是「3 条」这种计数）；③有向图的 $A$ 不对称，$A^2$ 也不对称，别按无向图对称去简化；④矩阵下标从 0 开始，别与教材的 1 起始混淆。

**第一性考点**
- **本质**：矩阵幂的每一项都是**「路径枚举的计数」**——矩阵乘法 $\sum_k$ 的求和下标就是路径的中间顶点。
- **判据**：题目出现「$A^m$」「非零元素含义」「路径条数」⇒ 用「长度为 $m$ 的路径条数」作答，且区分「恰为 $m$」与「不超过 $m$」。
- **迁移**：可达矩阵（把 $\sum$ 换成 $\lor$、乘换成 $\land$）、传递闭包、Warshall 算法、网络流中的路径计数都是同一结构；若边带权，则把「乘」换成「加」、「加」换成「min」得到最短路矩阵（Floyd）。

> ⚠ **待核验（图内数值）**：底本第 42 题的**图 $G$ 与 $A$、$A^2$ 的矩阵数值均以图片给出**，本机当前模型无图像输入通道，无法读出具体边与矩阵元素。已核对官方解答中的文字结论：$A^2$ 的 0 行 3 列元素值为 3、含义为「从顶点 0 到顶点 3 长度为 2 的路径有 3 条」；(3) 的结论如上。**$A$ 与 $A^2$ 的具体数值请对照底本 P5–P6 图与 P10 解答图**，本文件不臆造数据。

**变式自测**：若把 $A$ 的对角线全置 1（加自环）再求 $A^m$，0 行 3 列的计数会怎样变化？<details>会**变大**：自环使「原地停留一步」成为合法路径，长度 $m$ 的路径集合包含「长度 $m-1$ 的路径 + 一次停留」等更多组合，计数不再等于纯 $m$ 步路径数。这也说明「是否含自环」直接改变计数的语义。</details>

### 43.（13 分）单总线数据通路与控制信号
**题目与条件**：某 16 位计算机主存按字节编址、存取单位 16 位，采用 16 位定长指令字；CPU 为**单总线结构**，主要部件如底本 P6 图所示（**题面含图**）：R0～R3 为通用寄存器，T 为暂存器，SR 为移位寄存器（可直送 mov、左移 left、右移 right 三种操作，控制信号 SRop；SR 输出由 SRout 控制）；ALU 可做 mova、add、sub、and、or、not、inc 七种操作，控制信号 ALUop；另有 PC、MAR、MDR、存储器、二路选择器 MUX。回答：(1) 哪些寄存器程序员可见？为何设暂存器 T？(2) ALUop、SRop 至少各几位？(3) SRout 控制部件的名称或作用？(4) 端点 ①～⑨ 中哪些须连到控制部件输出端？(5) 为完善单总线数据通路，需在端点间补哪些连线（含方向）？(6) MUX 的一个输入端为什么是 2？

**解题思路**：单总线结构的特点是**任一时刻总线上只有一个数据**，所以所有「两个操作数同时进入 ALU」的场景都必须靠**暂存器**把其中一个先锁住。控制信号问题则一律从「有多少种互斥的操作」推位数（$\lceil\log_2 k\rceil$）。端点归属问题看「该端点是收控制信号（输入）还是从部件送往总线」。

**逐步推导**：
1. **程序员可见寄存器**：指汇编/机器指令能直接读写的寄存器，即 R0～R3 与 PC（可用转移指令改变 PC）；MAR、MDR、T、SR 都是对程序员透明的暂存部件。
2. **设 T 的必要性**：单总线同一时刻只送一个数据，而 ALU 的 A、B 两个端口若直接连总线，会同时得到同一个数据；故必须先用 T 暂存 A 端数据，下一拍再把 B 端数据送上总线。
3. **控制信号位数**：ALU 有 7 种操作 ⇒ $\lceil\log_2 7\rceil=3$ 位；SR 有 3 种操作 ⇒ $\lceil\log_2 3\rceil=2$ 位。
4. **SRout 的作用**：控制 SR 与总线之间的连接，实现为**三态门**（高阻态时断开，避免总线冲突）。
5. **端点归属**：①～⑨ 中属于「控制信号输入」的须接控制部件输出端：底本答案为 **①、②、③、⑤、⑧**；其余（④、⑥、⑦、⑨）是部件之间互相送数据的通路端点，不能接控制部件。
6. **补充连线**：为使数据能双向流动，需补两条线：**⑥→⑨** 与 **⑦→④**（方向按图中数据流动方向）。
7. **MUX 输入端为 2 的原因**：指令 16 位、按字节编址 ⇒ 一条指令占 2 个内存单元，顺序执行时下条指令地址为 $(PC)+2$；MUX 有常量 2 的输入，正好用于「PC 自增 2」这一操作。

**关键结论与适用条件**：单总线 CPU 的每个时钟周期只能完成**一次**总线传送，所以「取操作数 → 运算 → 写回」必须拆成多个周期（本题后续第 44 题即考到这个代价）；控制器输出端只接**控制类端点**，数据通路端点由部件间的连线构成。

**易错点**：①把 PC 当成「不可见」（PC 是程序员可见的，MAR/MDR 才是透明的）；②`ALUop` 位数算成 7 位（应取 $\lceil\log_2 7\rceil=3$，编码数不是位数）；③把 SRout 答成「控制移位方向」（方向由 SRop 给，SRout 只管**是否上总线**）；④端点题里把数据端点也算进控制部件输出端（底本评分说明：多答 ④⑥⑦⑨ 中任一个即不给分）；⑤补连线写成「单向数据线」而漏掉方向。

**第一性考点**
- **本质**：单总线数据通路的全部困难来自**「总线的时分复用」**——一个周期只能传一个数，于是必须用暂存器拆拍。
- **判据**：出现「n 种互斥操作」⇒ 控制信号位数为 $\lceil\log_2 n\rceil$；出现「两个操作数同时进 ALU」⇒ 必有一个先进暂存器。
- **迁移**：多总线（双总线/三总线）结构之所以能一拍完成 add，正是因为它解除了「同时只能传一个数」的约束；流水线 CPU 的「段寄存器」也是同一暂存思想的延伸。

**变式自测**：若把 ALU 的操作扩到 9 种，ALUop 需要几位？<details>仍是 4 位（$\lceil\log_2 9\rceil=4$）；注意 8 种以内是 3 位，一旦超过 8 就必须进位到 4 位——控制信号位数的临界点是 $2^k$。</details>

### 44.（10 分）指令格式与机器代码
**题目与条件**：题 43 中描述的计算机，其部分指令执行过程的控制信号如底本 P7 **题图 a**，指令格式如**题图 b**：16 位定长，含操作码（7 位）、寻址方式位、寄存器号（各 2 位，R0～R3 编号 0～3）等字段；支持寄存器直接（寻址方式位 0）与寄存器间接（1）两种方式。回答：(1) 最多可定义多少条指令？(2) `inc R1`、`shl R2,R1`、`sub R3,(R1),R2` 的机器代码（操作码分别 01H、02H、03H）？(3) 题图 a 中 ①～⑧ 处的控制信号或取值？(4) `sub R1,R3,(R2)` 与 `inc R1` 的执行阶段至少各几个时钟周期？

**解题思路**：机器代码题没有任何技巧，只有**「按字段宽度切位、按字段含义填值」**两步：先确定每个字段占几位、从高到低排列，再把助记符翻译成「操作码 + 寻址方式位 + 寄存器号」。时钟周期数则由「单总线一拍只能传一个数」逐拍数出来。

**逐步推导**：
1. **指令条数**：操作码 7 位 ⇒ 最多 $2^7=128$ 条。
2. **机器码**（按题图 b 的字段顺序：操作码 7 位 | 寻址方式 1 位 | 目的寄存器 2 位 | 寻址方式 1 位 | 源寄存器 2 位 | …，与底本一致）：
   - `inc R1`（操作码 01H=`0000001`，R1=`01`，其余位为 0）：`0000001 0 01 0 00 0 00` = `0240H`
   - `shl R2,R1`（02H=`0000010`，目的 R2=`10`，源 R1=`01`）：`0000010 0 10 0 01 0 00` = `0488H`
   - `sub R3,(R1),R2`（03H=`0000011`，目的 R3=`11`，源 1 为间接 `(R1)` ⇒ 寻址方式位 1、寄存器 `01`，源 2 R2=`10`）：`0000011 0 11 1 01 0 10` = `06EAH`
3. **控制信号取值**（底本答案）：① `0`；② `mov`；③ `mova`；④ `left`；⑤ `read`；⑥ `sub`；⑦ `mov`；⑧ `Srout`。
4. **时钟周期**：`sub R1,R3,(R2)` 需要「读 R3 上总线 → 读 (R2) 间接访存取操作数 → ALU 做减法 → 结果写回 R1」，单总线一拍一步 ⇒ **至少 4 个周期**；`inc R1` 只需「R1 送 ALU 加 1 → 写回 R1」⇒ **至少 2 个周期**。

**关键结论与适用条件**：16 位定长指令字下，字段一旦划分好，**寻址方式与寄存器号是逐操作数编码的**（每个源操作数各带 1 位方式位）；执行周期数取决于「访存次数 + 总线上传送次数」，与指令字长无关。

**易错点**：①机器码按二进制拼好后**十六进制换算错**（0240H 中的 `0` 位是寄存器 R0 的编号，容易漏）；②`(R1)` 是寄存器间接，方式位必须置 1，容易当直接寻址处理；③把「128 条」算成「7 位 = 7 条」；④周期数把「取指」算进去（题问的是**执行阶段**）；⑤控制信号与操作码混淆（`mov`/`mova` 是 ALU/SR 的操作码，`read` 是存储器控制）。

**第一性考点**
- **本质**：指令编码 = **「定长字里的字段划分 + 逐字段赋值」**，所有机器码题都是同一套位运算。
- **判据**：给助记符求机器码 ⇒ 先列字段位宽表，再逐字段填；求周期数 ⇒ 数「上总线的次数 + 访存次数」。
- **迁移**：扩充操作码（变长操作码）只是把字段重新划分；RISC 的定长指令正是靠这种规整字段实现单周期译码——本题就是它的原理版。

**变式自测**：若指令字长改为 32 位、寄存器扩到 8 个，每个寄存器号需要几位？<details>3 位（$\log_2 8$）。若同时把操作码保持 7 位、三寄存器 + 2 个方式位，字段共占 $7+3\times3+2=18$ 位，余下 14 位可放立即数或空闲位。</details>

**来源定位**：2015 408 第 44 题，底本 P6–P7（题面、题图 a/b）、P10–P11（官方解答与评分说明），fs_id 见溯源表。

### 45.（9 分）双信箱辩论的同步
**题目与条件**：A、B 两人通过信箱辩论：每人从自己信箱取出对方的问题，把「答案 + 新问题」组成邮件放入对方信箱。A 的信箱最多放 $M$ 封、B 的信箱最多放 $N$ 封；初始 A 信箱有 $x$ 封（$0<x<M$）、B 信箱有 $y$ 封（$0<y<N$）。取出一个邮件则数量减 1。A、B 的过程为 `while(TRUE){ 从自己信箱取一个邮件; 回答问题并提出新问题; 将新邮件放入对方信箱; }`。信箱不空才能取、不满才能放。要求：添加必要的信号量与 P/V 操作实现同步，写出完整过程并说明信号量含义与初值。

**解题思路**：这是**两个方向的生产者—消费者问题拼在一起**：A 是「A 信箱的消费者 + B 信箱的生产者」，B 正相反。所以每个信箱都要一对「资源信号量（当前邮件数）+ 剩余空间信号量」，另外每个信箱还需要一个**互斥信号量**保护信箱（可能有多个辩论者/中断）。

**逐步推导**：
1. 信号量定义：`Full_A = x`（A 信箱中现有邮件数）、`Empty_A = M-x`（A 信箱剩余空间）、`Full_B = y`、`Empty_B = N-y`；互斥：`mutex_A = 1`、`mutex_B = 1`。
2. A 取邮件：先 `P(Full_A)` 确保不空 → `P(mutex_A)` → 取 → `V(mutex_A)` → `V(Empty_A)` 释放一个空间。
3. A 放邮件到 B：先 `P(Empty_B)` 确保 B 有空间 → `P(mutex_B)` → 放 → `V(mutex_B)` → `V(Full_B)`。
4. B 的过程完全对称（取自己信箱用 `Full_B/mutex_B/Empty_B`，放对方信箱用 `Empty_A/mutex_A/Full_A`）。
5. 关键顺序：**先 P 资源信号量、再 P 互斥信号量**，释放时**先 V 互斥、再 V 资源**；两个 P 的顺序不能颠倒（否则持锁等待会死锁）。

```c
semaphore Full_A = x,  Empty_A = M - x;   // A 信箱的邮件数 / 剩余空间
semaphore Full_B = y,  Empty_B = N - y;   // B 信箱的邮件数 / 剩余空间
semaphore mutex_A = 1, mutex_B = 1;       // 两个信箱的互斥访问

A() {
    while (TRUE) {
        P(Full_A);   P(mutex_A);   从 A 的信箱中取出一个邮件;   V(mutex_A);   V(Empty_A);
        回答问题并提出一个新问题;
        P(Empty_B);  P(mutex_B);   将新邮件放入 B 的信箱;      V(mutex_B);   V(Full_B);
    }
}
B() {
    while (TRUE) {
        P(Full_B);   P(mutex_B);   从 B 的信箱中取出一个邮件;   V(mutex_B);   V(Empty_B);
        回答问题并提出一个新问题;
        P(Empty_A);  P(mutex_A);   将新邮件放入 A 的信箱;      V(mutex_A);   V(Full_A);
    }
}
```

**关键结论与适用条件**：每条「取/放」操作对应「一个资源信号量 + 一个互斥信号量」；资源信号量初值由**初始数量**给定（`x`、`y` 和 `M-x`、`N-y`），不能用固定的 0/1。同步信号量的 P/V 必须**成对出现在同一个信箱上**，且互斥的 P 必须在资源的 P 之后。

**易错点**：①把 `Full_A`、`Full_B` 初值写成 0 或 1（应按题给 $x$、$y$）；②`Empty` 与 `Full` 配错信箱——A 取自己的（`Full_A`）、放对方的（`Empty_B`），方向错就死锁；③漏掉 `mutex`（若只有一人辩论则可省，但题目未限定一人）；④`P(mutex)` 写在 `P(Full)` 之前（持锁等待 ⇒ 死锁）；⑤忘记「回答问题」这段不需要任何 P/V（它与信箱无关，可并发）。

**第一性考点**
- **本质**：同步 = **把「资源的存在性」和「空间的可用性」各用一个信号量表示**，P/V 的位置就是「使用前申请、使用后归还」。
- **判据**：出现「缓冲区/信箱 + 有界容量」⇒ 必是「生产者—消费者」；有几个缓冲方向就要几对 `Full/Empty`，容量有界就一定有 `Empty`。
- **迁移**：单缓冲区生产者—消费者、打印机的 spooling、流水线阶段间缓冲全是同一骨架；「有几个方向就乘几」是这类题的唯一扩展方式。

**变式自测**：若规定「同一时刻只能有一个人登录辩论」，需要加什么？<details>加一个互斥信号量 `mutex = 1`，在 A、B 的整个 `while` 体两端各加 `P(mutex)`/`V(mutex)`（或更合理地限制为「谁在讲话」信号量）。注意这样会让并发退化为串行——同步与互斥的边界就在这里：互斥保护共享数据，串行则破坏并发意义。</details>

**来源定位**：2015 408 第 45 题，底本 P7–P8（题面）、P11（官方解答与评分说明），fs_id 见溯源表。

### 46.（6 分）二级页表的地址转换
**题目与条件**：某系统按字节编址，采用二级页表分页存储管理，虚拟地址格式为：页目录号 10 位 | 页表索引 10 位 | 页内偏移 12 位。回答：(1) 页和页框大小各多少字节？进程虚拟地址空间多少页？(2) 页目录项和页表项均占 4 字节，则页目录和页表共占多少页（写出计算过程）？(3) 若某指令周期内访问虚拟地址 0100 0000H 和 0111 2048H，则地址转换共访问多少个二级页表？说明理由。

**解题思路**：二级页表题只有三步——**「按位宽切地址 → 算页表大小 → 数访问次数」**。页大小由页内偏移位数决定；页表项的个数由「上一级索引位数」决定；访问几个二级页表则看两个虚拟地址的**页目录号是否相同**（相同则共用一个二级页表）。

**逐步推导**：
1. **页/页框大小**：页内偏移 12 位 ⇒ $2^{12}=4$KB。页框与页大小相同，也是 4KB。
2. **虚拟地址空间页数**：页目录 10 位 + 页表 10 位 = 20 位页号 ⇒ $2^{20}$ 页（虚拟地址空间 $2^{32}$B $=4$GB）。
3. **页目录占页数**：页目录项数 $=2^{10}$，每项 4B ⇒ $2^{10}\times4=4096$B $=1$ 页。
4. **页表占页数**：页表项总数 $=2^{20}$，每项 4B ⇒ $2^{20}\times4=4$MB ⇒ $4\text{MB}/4\text{KB}=2^{10}=1024$ 页。
5. 合计 $1+1024=1025$ 页。
6. **第 (3) 问**：把两个地址的高 10 位（页目录号）取出：
   - `0100 0000H` = `0000 0001 0000 0000 …`，最高 10 位 = `0000000100` = 4
   - `0111 2048H` = `0000 0001 0001 0001 0010 …`，最高 10 位仍 = `0000000100` = 4
   两者页目录号相同 ⇒ 指向**同一个二级页表** ⇒ 只访问 **1 个**二级页表。

**关键结论与适用条件**：页大小 $=2^{\text{偏移位数}}$；页目录/页表占用页数 $=\dfrac{\text{项数}\times\text{项宽}}{\text{页大小}}$；「访问几个二级页表」只看页目录号是否相同（同一进程内）。注意多级页表的目的是**让页表可以不连续存放、按需调入**，而不是减少总页表大小（本题 1025 页的总量不变）。

**易错点**：①把页目录号与页表索引的位数搞反（本题各 10 位，若不等则结论会变）；②算页表占页数时忘记乘 4B（$2^{20}$ 项直接当成 $2^{20}$ 字节会少算 4 倍）；③第 (3) 问错答 2 个（误以为两个不同虚拟地址一定要两个二级页表）；④页大小算成 4KB 后把页框大小答成别的值（页框 = 页，永远相同）；⑤漏掉「页目录自身也占 1 页」。

**第一性考点**
- **本质**：多级页表把「一个大页表」拆成「树」，用**多次访存换空间连续性**；页大小决定树的分叉宽度。
- **判据**：页大小由偏移位数定；某一级页表的项数由**指向它的索引位数**定；问「访问几次页表」则数地址经过的层数。
- **迁移**：三级/四级页表只是多切几段；TLB 命中可省掉全部页表访存；「快表 + 二级页表」的有效访存时间计算题，本质就是本题的层数 × 每层访存代价。

**变式自测**：若页内偏移改为 13 位、页目录号与页表索引各 9 位，则页大小与页目录占页数各是多少？<details>页大小 $=2^{13}=8$KB；页目录项数 $2^{9}=512$，每项 4B = 2048B，$2048/8192<1$ ⇒ 占 1 页（不足一页仍占整页）。页表项 $2^{18}$ 项 × 4B = 1MB ⇒ 128 页。</details>

### 47.（9 分）网络拓扑与 DHCP/ARP（**题面含图 · 部分地址待核验**）
**题目与条件**：某网络拓扑如底本 P8 图（**题面含图**）：路由器内网接口、DHCP 服务器、WWW 服务器、主机 1 均配静态 IP，相关地址见图中标注；主机 2～主机 N 通过 DHCP 动态获取地址。回答：(1) DHCP 可为主机 2～N 分配的 IP 最大范围？主机 2 的 DHCP Discover 报文的源/目的 IP？(2) 主机 2 的 ARP 表为空时，它访问 Internet 发出的第一个以太网帧的目的 MAC？封装其发往 Internet 的 IP 分组的以太网帧目的 MAC？(3) 若主机 1 的子网掩码与默认网关分别配为 255.255.255.0 和 111.123.15.2，它能否访问 WWW 服务器？能否访问 Internet？说明理由。

**解题思路**：三道小题各对应一个固定判据：**DHCP 的范围 = 子网内去掉网络地址、广播地址和已静态占用的地址**；**ARP 的目的 MAC 取决于「下一跳是网关还是同网段主机」**；**可达性判断取决于「目的 IP 与本机掩码运算后是否同网段」以及「默认网关是否配置正确」**。

**逐步推导**：
1. **(1) 地址范围**：内网子网为 111.123.15.0/24（地址见图中标注），去掉网络地址 .0、广播地址 .255，以及已被静态占用的 .1（路由器内网接口）、.2（DHCP 服务器？底本标注）、.3（WWW 服务器）、.4（主机 1）等 ⇒ DHCP 可分配范围为 **111.123.15.5～111.123.15.254**。主机 2 尚无 IP，DHCP Discover 的源 IP 为 **0.0.0.0**（本机未配置地址）、目的 IP 为 **255.255.255.255**（广播，因还不知道服务器地址）。
2. **(2) 第一个帧的目的 MAC**：ARP 表为空时主机 2 要先解析「默认网关」的 MAC，发出的是 **ARP 请求**，目的 MAC 为 **ff-ff-ff-ff-ff-ff**（广播）。封装「发往 Internet 的 IP 分组」的帧，其目的 MAC 是**路由器内网接口的 MAC**（图中标注 **00-a1-a1-a1-a1-a1**），因为跨网段流量必须交给网关转发。
3. **(3) 主机 1 的可达性**：子网掩码 255.255.255.0 与 111.123.15.4 相与得 111.123.15.0；WWW 服务器同在此子网 ⇒ **能访问 WWW 服务器**（同网段直连，不需要网关）。默认网关却配成了 111.123.15.2（正确应为 111.123.15.1）⇒ 主机 1 访问 Internet 时，跨网段分组被送到**错误的下一跳** .2，无法到达 ⇒ **不能访问 Internet**。

**关键结论与适用条件**：同一子网内的通信只需 ARP 解析目的主机 MAC；跨子网通信一律「帧的目的 MAC = 网关 MAC、IP 的目的地址 = 最终目的」。默认网关配错只影响**跨网段**业务，不影响同网段访问——这正是本题第 (3) 问的设计意图。

**易错点**：①DHCP 范围把网络地址/广播地址也算进去；②Discover 的源 IP 写成主机 1 的地址（应为 0.0.0.0）；③第一个帧的目的 MAC 写成路由器 MAC（ARP 解析前只能用广播）；④把「能访问 WWW、不能访问 Internet」答成「两个都不能」或「两个都能」；⑤未指出默认网关的正确值是 .1。

**第一性考点**
- **本质**：IP 层决定「送到哪」，链路层决定「交给谁」——**帧的 MAC 永远是「下一跳」的 MAC，不是最终目的地的 MAC**。
- **判据**：目的与本机同子网 ⇒ 帧目的 MAC = 目的主机；跨子网 ⇒ 帧目的 MAC = 默认网关。可达性判断一律「IP 与掩码相与比子网号」。
- **迁移**：NAT（本题路由器内网接口做 NAT）、代理 ARP、VLAN 间路由都从「下一跳」这一条推出来；DHCP 的 DORA 四步（Discover-Offer-Request-ACK）也是「先广播找服务器、再单播确认」。

**变式自测**：若主机 1 的子网掩码被误配为 255.255.255.128，它还能访问 WWW 服务器（设为 111.123.15.3）吗？<details>能。111.123.15.4 与 111.123.15.3 在 /25 下同属 111.123.15.0/25 子网（范围 .0–.127），仍同网段直连。但若 WWW 服务器地址落在 .128–.255 段，就会被判为跨网段而错误地走网关——这也是「掩码错配」最常见的表现形式。</details>
