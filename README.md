# 考研真题逐题详解（数学一 / 408）

把百度网盘里的历年真题 PDF，转成「一道题一详解 + 第一性考点」的结构化笔记，并同步到 Notion / FlowUs / GitHub。

- 数据源：百度网盘 `/08-考研考证/`（账号 VIP，xpan `filemetas?dlink=1` 直连下载）
- 解析：PyMuPDF 渲染 → 逐页读图转录（数学公式 LaTeX 化）；可抽文本的年份直接用文本层
- 生产规范：沿用网盘内 `301/408图文笔记生产规范.md` 的模板与状态机
- 同步目标：Notion（`考研数学教程库` 下）、FlowUs（`Cacinie` 工作区）、本仓库（GitHub Pages）

## 进度与扩量策略

全量口径：数学一 2008–2025 共 18 年，408 2009–2025 共 17 年（408 上限由考试制度决定），
按每年 22/23 题与 47 题估算约 **1100 道题**。逐题详解属于「一题一段推理」的体力活，
必须一题一题写、一题一题对照答案，不是能靠脚本批量刷出来的。

当前已交付 7 份：数学一 2024、2025；408 2015、2016、2017、2018、2019。
剩余年份按 `02-分类体系.md` 的 B5–B12 批次推进。

## 一键复用

```bash
# 1) 取文件（改 want 列表里的路径即可）
python3 pipeline/bd_fetch.py dl <fs_id> /tmp/out.pdf

# 2) 递归盘点某一目录下所有 PDF
python3 pipeline/survey_pdf.py '/08-考研考证/301-03-历年真题与模考/来源-08-01 历年真题_2010-2025/数学一真题'

# 3) 判断是「文本型」还是「扫描型」，并渲染成图
python3 pipeline/render_pdf.py /tmp/out.pdf
```
